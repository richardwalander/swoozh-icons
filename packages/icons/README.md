# @swoozh/icons

SVG files, sprites and path data for Swoozh Icons.

```js
import { ShoppingBag, toSvg } from '@swoozh/icons';
el.innerHTML = toSvg(ShoppingBag, { variant: 'filled', size: 20 });
```

Files: `dist/svg/{outline,filled}/<name>.svg`, `dist/sprite-outline.svg`, `dist/sprite-filled.svg`, `dist/icons.json`.

Full docs: `site/docs.html`.
