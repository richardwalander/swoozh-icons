# swoozh/icons

Swoozh Icons for Elm.

```elm
import SwoozhIcons exposing (Variant(..))

SwoozhIcons.shoppingBag Filled [ Svg.Attributes.width "32", Svg.Attributes.height "32" ]
```

`src/SwoozhIcons.elm` is generated by `npm run build` in the repo root. The license in `elm.json` is a placeholder until a license is chosen.

Full docs: `site/docs.html`.
